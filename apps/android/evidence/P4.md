## Boundaries

The full physical-device/accessibility/large-screen matrix, ten-thousand-record performance, notification delivery, actual disk-full or process-death-mid-transaction faults, signed legacy-app migration, multiple currencies/refunds/savings withdrawals, and cloud provider upload/retention/recovery remain open. Actual cash posting is explicit; no background scheduler posts financial entries. The external Files UI itself was not automated; CSV's native content-resolver write and the disclosure flow were exercised. No Internet permission, remote AI, credentials, cloud transport or production release was added. Changes stay under `apps/android/`; integrator owns staging and generated documentation.
